# Android Phone Emulator

A modern Android emulator for Windows with a realistic phone interface.

Unlike the standard Android Emulator UI, Android Phone Emulator embeds the Android display into a custom device frame, providing a clean and intuitive user experience for testing Android applications.

## Features
📱 Realistic phone-style interface
🤖 Bundled Android 16 AOSP image
⚡ Fast startup
🔄 Screen rotation
🖥 Native Windows desktop application
🎨 Clean custom UI
📦 Standalone distribution
🌐 Optional download of additional Android system images
🔧 Based on the official Android Emulator runtime
Included Runtime

## This project includes support for:

Android Emulator
Android 16 AOSP
Android Virtual Devices (AVD)
Optional Google system images (downloaded separately)
Requirements
Windows 10 or Windows 11 (64-bit)
CPU virtualization enabled in BIOS/UEFI
Hardware virtualization support is recommended
Approximately 10 GB of free disk space
Installation
Download the latest release.
Extract the archive.
Start AndroidPhoneEmulator.exe.
Select an Android version if desired.
Launch the virtual device.
Android Images

The application includes a bundled Android 16 AOSP image.

Additional Android images can optionally be downloaded using the integrated image manager.

Google APIs and Google Play system images are subject to Google's licensing terms and are downloaded separately.
